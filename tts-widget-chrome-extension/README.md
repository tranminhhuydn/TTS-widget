# TTS-widget – Chrome Extension

Thư mục này dành riêng cho việc triển khai TTS-widget dưới dạng Chrome Extension.

## Trạng thái

Đây là khu vực khởi tạo cho phiên bản Extension. Chưa có bản Extension hoàn chỉnh trong thư mục này.

## Phạm vi

- Tích hợp và tái sử dụng lõi TTS-widget hiện có khi phù hợp.
- Xây dựng các thành phần đặc thù của Chrome Extension trong thư mục này.
- Quản lý yêu cầu và quy tắc phát triển riêng tại [`prompts.md`](./prompts.md).

## Tách biệt với phiên bản nhúng website

Phiên bản nhúng website nằm tại [`../tts-widget-embeding-web/`](../tts-widget-embeding-web/). Không tự ý sửa, di chuyển, đổi tên hoặc thay đổi prompts/mã nguồn trong thư mục đó khi thực hiện công việc cho Extension.

Nếu cần thay đổi lõi dùng chung, phải trình bày lý do, các tệp bị ảnh hưởng và phương án tương thích; chỉ thực hiện sau khi đã thống nhất.
